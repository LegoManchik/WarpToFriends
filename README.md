# Warp To Friends 1.6.15 Fork

Modernized fork of Warp To Friends for Stardew Valley 1.6.15+ with added stamina/energy cost per teleport, full multiplayer energy synchronization, and GMCM configuration support.

---

## 📋 Особенности / Features
- Разработано специально для **Stardew Valley 1.6.14 - 1.6.15+** и **SMAPI 4.0+**.
- Полная интеграция с **Generic Mod Config Menu (GMCM)**.
- Чистый, высокопроизводительный код на C# (.NET 6).

---

## 🛠️ Сборка из исходников / Building from source
1. Установите [.NET 6.0 SDK](https://dotnet.microsoft.com/download/dotnet/6.0).
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/LegoManchik/WarpToFriends.git
   cd WarpToFriends
   ```
3. Скомпилируйте проект:
   ```bash
   dotnet build -c Release
   ```
4. Скомпилированные файлы (`.dll`, `manifest.json`, ресурсы) появятся в папке `bin/Release/net6.0/`.
